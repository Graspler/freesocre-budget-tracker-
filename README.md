# Free Score Budget and Expense Tracker

A simple budget and expense tracker built using GCSE level Python code. This application helps you track your income and expenses with an easy-to-use command-line interface.

## Features

- ✅ Add income transactions
- ✅ Add expense transactions
- ✅ View current balance
- ✅ View transaction history
- ✅ View budget summary (total income, expenses, and balance)

## GCSE Level Concepts Used

This project demonstrates fundamental programming concepts suitable for GCSE Computer Science:

1. **Variables** - Storing balance and transaction data
2. **Data Types** - Numbers (float), strings, booleans
3. **Lists** - Storing multiple transactions
4. **Dictionaries** - Storing transaction details
5. **Functions** - Breaking code into reusable chunks
6. **Loops** - `while` loop for menu, `for` loop for displaying transactions
7. **Conditional Statements** - `if/elif/else` for menu choices
8. **Input/Output** - Getting user input and displaying results
9. **String Formatting** - Displaying currency values

## How to Run

1. Make sure you have Python installed (Python 3.x)
2. Navigate to the project directory
3. Run the program:
   ```bash
   python budget_tracker.py
   ```

## How to Use

When you run the program, you'll see a menu with these options:

1. **Add Income** - Record money you've received
2. **Add Expense** - Record money you've spent
3. **View Balance** - Check your current balance
4. **View Transactions** - See all your income and expenses
5. **View Summary** - See totals for income, expenses, and balance
6. **Exit** - Close the program
