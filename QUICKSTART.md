# Quick Start Guide

## Get Started in 3 Easy Steps!

### Step 1: Open your terminal or command prompt

### Step 2: Navigate to the project folder
```bash
cd path/to/freesocre-budget-tracker-
```

### Step 3: Run the program
```bash
python budget_tracker.py
```

## Your First Budget Entry

When the menu appears, try this:

1. Press `1` to add income
   - Enter an amount like `100`
   - Enter a description like `Pocket money`

2. Press `2` to add an expense
   - Enter an amount like `15`
   - Enter a description like `Snacks`

3. Press `5` to see your summary
   - This shows your total income, expenses, and balance

4. Press `6` to exit when you're done

## Tips

- You can add as many transactions as you want
- The balance updates automatically after each transaction
- All amounts should be numbers (like 10 or 15.50)
- Use option 4 to see all your transaction history
